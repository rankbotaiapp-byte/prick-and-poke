# Use this template for one company

Master repo: axiomHalotemplate. Do not put a live client name in here.

1. Scout the shop. Skip if they already have an AI desk.
2. Copy business.ts (or Make shop repo).
3. New repo from this template, named after the shop.
4. Paste over src/config/business.ts and keep active: true.
5. Deploy that new repo on Vercel.
6. Customer link = the shop. Owner edits later at /admin with PIN 4242.

Owner can change photos, hours, albums, and services in Desk without touching code.
You can still edit business.ts and deploy again if the shop data needs a reset.
